# Идея


**Именной алгоритм/метод:**
Для этой задачи нет специального именного алгоритма, но есть  **классическое итеративное решение с O(1) дополнительной памяти** .

**Лучшее возможное время:**

* **Время:** O(n), где n — количество узлов (нужно пройти хотя бы раз по всем узлам).
* **Память:** O(1) (перестановка ссылок, без создания новых узлов).

**Особенность:**
Задачу **нельзя** решить быстрее O(n), так как каждый узел нужно хотя бы один раз посетить для определения пар. Однако использование `O(1)` памяти — достижимо и является оптимальным.
